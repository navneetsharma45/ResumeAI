# 🚀 ResumeAI – AI Powered ATS Resume Analyzer

ResumeAI is a full-stack AI application that analyzes resumes against job descriptions, calculates ATS compatibility, and rewrites resumes to improve job matching.

## ✨ Features

- 📄 Upload PDF Resume
- 🤖 AI Resume Analysis using Gemini
- 📊 ATS Score
- 🎯 Job Match Score
- 📝 AI Summary
- 💪 Strengths & Weaknesses
- 🧠 Skills & Missing Skills
- 💡 AI Suggestions
- ✨ AI Resume Rewriter
- 📋 Copy Rewritten Resume
- 📥 Download Rewritten Resume
- 📄 Download PDF Report
- 👀 Resume Preview with Zoom

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- React PDF
- Axios

### Backend
- Node.js
- Express.js
- Multer
- PDF-Parse

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/navneetsharma45/ResumeAI.git
```

### Install dependencies

```bash
npm install
```

### Start Backend

```bash
cd backend
npm install
npm run dev
```

### Start Frontend

```bash
cd frontend
npm install
npm run dev
```
